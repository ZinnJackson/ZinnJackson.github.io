# Jackson Zinn

A simple, responsive personal website built with plain HTML and CSS. It is ready to publish with GitHub Pages from the repository root.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. Save. GitHub will provide the published site URL on the Pages settings screen.

Edit `index.html` to update the page content, colors, or links. The GitHub profile link currently points to `github.com/ZinnJackson`.
